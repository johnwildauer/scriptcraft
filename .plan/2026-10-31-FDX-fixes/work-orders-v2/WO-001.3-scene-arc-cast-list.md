# V2-WO-001.3 — Cast List from scene arc data

- **Status:** Implemented; user-owned review and validation pending
- **Depends on:** [V2-WO-001.2](WO-001.2-scene-properties-and-arc-reconciliation.md)
- **Validation:** User-owned; no agent-run checks

## Outcome

Make Cast List updates consume the synchronized scene arc projection instead of independently rescanning Character elements.

## Scope

- Run scene-metadata reconciliation before Cast List derivation in [`correct_cast_lists()`](../../../crates/scriptcraft-core/src/cast_list.rs:35).
- Read recognized CharacterArcBeat names from preserved SceneArcBeats after reconciliation. For a never-saved project without preservation, consume the same shared derived projection rather than duplicating collection rules.
- Keep existing alphabetical case-insensitive ordering, parenthesized Cast List formatting, first-spelling behavior, scene ranges, formatted-list safe-stops, and refresh cadence.
- Use the same ordered update for scheduled refresh, detached Save/Save As preparation, and undo/redo correction. Publish scene metadata and Cast List changes in the same candidate.
- Do not add SceneProperties Page/Length recalculation or arc-editing UI.

## Regression coverage

Prove arc data and Cast List text agree after Character add/rename/delete, across scenes, after undo/redo, after Save/reopen, and on detached save candidates. Verify lists before the first heading and documents without headings remain unchanged.

## Durable records

Update [the technical context](../../../.forge/blueprints/technical-context.md:49) and [the product overview](../../../.forge/requirements/product-overview.md:20) to identify SceneArcBeats as native derived scene-cast storage used by Cast List presentation.
