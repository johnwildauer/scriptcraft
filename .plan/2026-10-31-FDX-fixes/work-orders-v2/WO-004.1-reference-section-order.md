## Implementation handoff — 2026-11-02

The writer emits exactly the reference-compatible declaration `<?xml version="1.0" encoding="UTF-8" standalone="no" ?>` at the beginning of each serialization. It is written once outside the preserved XML tree; declaration events are not retained by the bounded reader, so writing a reopened document starts from a fresh single declaration rather than accumulating prior declarations. New ScriptCraft documents now emit Content, the existing 17 ElementSettings in native role order, and TitlePage only when present. Imported documents continue to serialize their retained root children in source order; no other Final Draft sections are generated or reordered. The existing namespace-aware reader, semantic checks, preservation-tree comparison, identity checks, and transactional save path were not weakened or redesigned.

Focused regression cases were authored in [`fdx.rs`](../../../crates/scriptcraft-core/src/fdx.rs) for exact declaration bytes/count, generated order with and without TitlePage across repeated read/write cycles, and unchanged imported top-level order. No tests, builds, lint, formatting, manual verification, implementation checks, reviews, validator dispatches, or other validation were run; authored cases are not results, and user-owned review/validation remain pending under [the project policy](../../../.forge/project-manifest.md:73).
