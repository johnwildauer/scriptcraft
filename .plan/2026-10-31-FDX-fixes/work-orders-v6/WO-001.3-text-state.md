# V6-WO-001.3 — Root TextState restore and overwrite

- **Status:** Implemented 2026-11-03; regression coverage authored but not executed; user validation pending
- **Depends on:** V6-WO-001.1 save-scoped candidate input; V6-WO-001.2 shared root view-state projection and insertion order
- **Validation:** User-owned; no agent-run checks or independent validators

## Objective

Read the direct root TextState once on Open, restore page zoom and screenplay Selection with safe defaults, and overwrite that root block from current editor state on every Save/Save As. Keep the separate TitlePage TextState source-preserved and never apply it to the body editor.

## Reference contract

Root examples include:

- [`reference2.fdx`](../../../.reference/reference2.fdx:171): Scaling 100, Selection 403,403, ShowInvisibles No.
- [`real_script_example.fdx`](../../../.reference/real_script_example.fdx:110): Scaling 75, Selection 1277,1277, ShowInvisibles No.
- [`arc copy.fdx`](../../../.reference/arc%20copy.fdx:105): Scaling 100, Selection 48,48, ShowInvisibles No.

Each also has a distinct nested TitlePage TextState, such as [`real_script_example.fdx`](../../../.reference/real_script_example.fdx:275) with Selection 14,20. Root projection must exclude that nested value by construction.

## Scope

1. Project direct root Scaling and Selection during deserialization.
2. Restore valid page zoom and Selection once after successful document activation.
3. Convert between flat FDX offsets and the existing element-plus-UTF-8-byte Selection with a bounded reversible mapping.
4. Save current ordered Selection and whole-percent zoom into one canonical root TextState.
5. Generate defaults for new documents and preserve nested TitlePage TextState.
6. Keep zoom/selection changes outside canonical content, dirty state, undo history, fixed layout, and exports.

## Non-goals

- No WindowState geometry behavior beyond sharing 001.2's view-state handoff.
- No ShowInvisibles editing feature; V6 writes No.
- No persistent backward-selection direction, scroll position, IME state, or undo history.
- No claim that the proposed flat-offset units are proven Final Draft parity.
- No OS presentation scaling changes; that is 001.4.
- No agent-run tests, desktop automation, Final Draft automation, review, or validation.

## Implementation requirements

### 1. Project only direct root TextState

Extend the reader's typed view-state result with root Scaling and Selection. Match only a direct child of FinalDraft and never a descendant of TitlePage.

Scaling rules:

- missing, malformed, zero, negative, or overflowing Scaling becomes 100;
- a valid numeric value is then normalized by the existing desktop limits, so values below 75 become 75 and values above 300 become 300;
- duplicate or ambiguous root TextState blocks use the safe default rather than selecting one arbitrarily;
- unusable disposable state does not block screenplay Open.

Selection rules:

- require exactly two nonnegative comma-separated integers in start,end order;
- reject malformed, overflowing, reversed, out-of-range, or non-boundary mappings as a complete selection;
- any rejected pair becomes caret 0,0 rather than clamping one endpoint into an unintended range.

ShowInvisibles has no supported editor feature in this order. Generated/saved output writes No and does not preserve the imported root value as application policy.

### 2. Implement explicit flat-offset mapping

Use this **agent-default** mapping for ScriptCraft round trips:

- concatenate canonical body text in semantic element order;
- count UTF-16 code units in each element's canonical text;
- insert one UTF-16 code-unit paragraph separator between adjacent body paragraphs;
- exclude TitlePage, SceneProperties, CharacterArcBeat paragraphs, and all non-body opaque content;
- map an endpoint inside element text to that element index and the corresponding canonical UTF-8 byte boundary;
- map the boundary before a paragraph separator to the end of the current element and the boundary after it to the start of the next element;
- map total length to the end of the last body element;
- reject an endpoint that splits a UTF-16 surrogate pair or has no valid UTF-8 mapping.

For Save, order the existing Selection's anchor/focus and project both positions into the same flat coordinate space. FDX does not retain backward selection direction in this bounded contract. Canonical text, runs, AllCaps presentation, and display-expanded uppercase do not affect the mapping.

Isolate the conversion in a focused core helper/module with direct tests rather than embedding offset arithmetic throughout the XML reader or desktop.

### 3. Restore zoom and Selection once

After constructing the replacement session in [`activate_opened_project()`](../../../apps/scriptcraft/src/main.rs:475):

- apply restored Selection through [`set_selection()`](../../../crates/scriptcraft-core/src/editing.rs:257);
- if the validated mapping unexpectedly fails at application, retain the safe caret 0,0 rather than partially applying a selection;
- set the app's whole-percent page zoom and synchronize the pinch baseline through [`sync_pinch_zoom_from_controls()`](../../../apps/scriptcraft/src/main.rs:262);
- invalidate presentation geometry as required by a zoom change without rebuilding canonical content;
- do not add an edit/undo entry or mark the document dirty;
- do not reapply the imported Selection or Scaling on later frames.

### 4. Capture and overwrite on Save

Extend the save-scoped view input with current Selection and current page zoom.

For preservation-free output, generate TextState immediately after WindowState and before ElementSettings with attributes in reference order: Scaling, Selection, ShowInvisibles. Defaults are Scaling 100, Selection 0,0, ShowInvisibles No when no runtime snapshot exists.

For imported actual Save/Save As:

- replace the direct root TextState with one canonical element containing current ordered Selection and current zoom;
- if missing, insert immediately after WindowState;
- replace duplicate root blocks with one because root TextState is explicitly disposable;
- leave nested TitlePage TextState unchanged, including its Scaling, Selection, attributes, and source position;
- include any bounded inserted-element whitespace in the detached expected tree;
- do not change fixed pagination or PDF/plain-text export state.

Direct source-backed serialization outside transactional Save retains imported root TextState unchanged. Zoom or caret movement before Save does not itself mutate Project or preservation.

### 5. Retain transaction and session behavior

Prepare the new root TextState only in the detached candidate. Codec, identity, source-tree, conflict, or storage failure publishes neither zoom nor Selection into live preservation or the destination.

Successful Save uses the existing selection-preserving rebase and does not unexpectedly move the caret to a stale imported value. The session-open wall-clock timestamp from 001.1/001.5 remains unchanged by this view-state work and is independent of imported DocumentRef DateTime.

## Implementation record — 2026-11-03

Implemented V6-WO-001.3 only, on top of the completed 001.1 save-scoped lineage and 001.2 WindowState work. `FdxDocument` now exposes a typed TextState derived solely from exactly one direct child of the FinalDraft root in the matching expanded namespace. Missing/duplicate state defaults to Scaling 100 and Selection 0,0; invalid/missing/nonpositive/overflowing Scaling defaults to 100, and valid numeric values clamp to 75–300. Selection parsing accepts exactly two unsigned decimal offsets; malformed, reversed, out-of-range, surrogate-splitting, invalid-UTF-8-boundary, and otherwise unmappable pairs become the complete caret 0,0.

The reversible mapping is isolated in core [`text_state.rs`](../../../crates/scriptcraft-core/src/text_state.rs). It counts UTF-16 code units in semantic body elements' canonical text, adds one separator between adjacent body paragraphs, excludes TitlePage, SceneProperties, CharacterArcBeat and opaque/non-body content, and maps valid endpoints to element-index/UTF-8-byte Positions. Save maps the live Selection into ordered offsets without changing selection direction in memory; AllCaps presentation does not affect offsets. After successful Open activation, the desktop applies Selection once via `set_selection()`, applies bounded page zoom, synchronizes pinch state, and invalidates presentation geometry. Zoom/caret remain outside Project, revision, dirty/history, fixed layout, and exports.

The save-scoped view-state input carries current Selection and zoom with WindowState. Transactional Save/Save As overwrite duplicate direct-root TextState blocks with one canonical Scaling/Selection/ShowInvisibles=No element; a missing block is inserted after WindowState. New preservation-free output emits TextState immediately after WindowState with Scaling 100, Selection 0,0 and ShowInvisibles No. Direct source-backed serialization outside Save remains unchanged. Nested TitlePage TextState and unrelated source remain preserved. Candidate tree reconciliation, identity/source checks, conflict detection, and atomic publication remain unchanged; failed saves publish no staged view state. No 001.4 physical presentation-scaling behavior was implemented.
