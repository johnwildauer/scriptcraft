# V2-WO-002.4 — Privacy-safe managed-edit and derived-failure diagnostics

- **Status:** Implementation submitted 2026-11-04; user validation pending
- **Initiative:** [`ui-quality-of-life-v2-zoom-and-typing.md`](../ui-quality-of-life-v2-zoom-and-typing.md)
- **Depends on:** V2-WO-002.3
- **Validation owner:** User; no agent-run checks or independent validators

## Objective

Make ManagedTextMismatch and scheduled Cast List failures identifiable by a bounded call-site/category without exposing screenplay text, IDs, source values, paths, or XML.

## Scope

1. Add a value-free diagnostic category for the distinct ManagedTextMismatch sites in [`replace_managed_text()`](../../crates/scriptcraft-core/src/preservation.rs:1215), [`replace_managed_text_elements()`](../../crates/scriptcraft-core/src/preservation.rs:1304), [`remove_managed_paragraph()`](../../crates/scriptcraft-core/src/preservation.rs:1626), and [`validate_scoped_managed_edit()`](../../crates/scriptcraft-core/src/preservation.rs:819).
2. Preserve existing error behavior and public compatibility where practical; if an error variant or public diagnostic shape changes, record the source-compatibility impact.
3. Propagate a bounded category through [`EditError`](../../crates/scriptcraft-core/src/editing.rs) and the desktop's ordinary [`show_error()`](../../apps/scriptcraft/src/main.rs:1012) path.
4. In the scheduled-refresh error arm in [`refresh_cast_lists_on_schedule()`](../../apps/scriptcraft/src/main.rs:542), replace discarded error information with a concise category identifying scene reconciliation, Cast List source mapping, model validation, or another existing safe error class. Do not include document-owned values.
5. Add focused formatting/propagation tests for every diagnostic site and the scheduler message. Tests are authored, not run.

## Boundaries

- Do not change retry behavior, relevance classification, reconciliation output, or validation strictness.
- Do not fix the Scene Heading or Cast List defect in this order.
- Do not add raw error payloads, source snippets, IDs, or filesystem details.

## Structural acceptance

- Each existing ManagedTextMismatch site has a distinct stable diagnostic category while returning the same failure and rollback outcome.
- Scheduled refresh no longer erases the safe failure category needed to localize the user's document failure.
- Existing session-health wording need not change except for the appended bounded category.

## Handoff

V2-WO-002.5 changes failed-refresh retry state only. V2-WO-002.6 and V2-WO-002.7 use these categories in focused correctness reproductions.

## Implementation submission — 2026-11-04

- Added `ManagedTextMismatchSite` and `PreservationError::ManagedTextMismatchAt` with the bounded labels `scoped-edit-validation`, `text-replacement`, `text-elements-replacement`, and `paragraph-removal`. The previous unit variant remains available for unrelated/internal mismatch paths. Mismatch return/rollback outcomes are unchanged.
- Propagated these labels through `EditError`; ordinary edit failures display the safe call-site category instead of debug payloads for categorized mismatches.
- Scheduled-refresh failures now append a bounded category to desktop status: scene reconciliation, Cast List source mapping, model validation, formatted Cast List mapping, or other safe refresh failure. No document text, identity, source value, path, or XML is included; retry and refresh behavior are unchanged.
- **API impact:** adding a public `PreservationError` variant can require downstream exhaustive matches to handle it. The public site enum and `EditError` diagnostic/category methods are additive. The existing `ManagedTextMismatch` unit variant is retained.
- **Authored, not run:** focused preservation coverage exercises all four mismatch sites and checks diagnostic values are absent; core editing coverage checks EditError propagation and scheduled category mapping; desktop coverage checks the scheduled status wording. Tests are in [`preservation.rs`](../../../crates/scriptcraft-core/src/preservation.rs), [`editing.rs`](../../../crates/scriptcraft-core/src/editing.rs), and [`main.rs`](../../../apps/scriptcraft/src/main.rs).
- **Limitations:** repository policy prohibits agent-run tests, builds, lint, formatting, implementation checks, reviews, and validation; none were run. User-owned validation remains pending.
